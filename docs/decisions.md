# Decisiones técnicas

Este índice registra decisiones técnicas duraderas y su justificación. Cada decisión se guarda en `docs/decisions/` con el formato `NNN-tema.md`, usando números consecutivos de tres cifras.

Cada documento debe indicar contexto, decisión, consecuencias, riesgos o alternativas consideradas y cómo revertirla cuando aplique. No incluya secretos, datos personales, tokens ni enlaces privados. Las decisiones sustituidas se conservan y se marcan como reemplazadas, enlazando a la nueva decisión.
